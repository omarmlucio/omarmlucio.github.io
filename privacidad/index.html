Política de privacidad

Omar's 2nd. Brain es una aplicación personal de un único usuario, su dueño.

  • Qué datos usa: los correos del buzón de Gmail del propio asistente, que solo recibe lo que el dueño le reenvía. No accede a ningún otro buzón.
  • Para qué: extraer avisos (alertas de consumo, estados de cuenta, alertas de facturación) y marcarlos como procesados.
  • Dónde se guardan: en los equipos del dueño. No se venden, no se comparten con terceros y no se usan para publicidad.
  • Revocar el acceso: en cualquier momento, desde myaccount.google.com/permissions.

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
